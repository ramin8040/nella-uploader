# مرکز پخش موسیقی نلا (Music Streaming Center)

پلتفرم پیشرفته و مدرن استریم اختصاصی موزیک با زبان فارسی (RTL)، معماری تمیز و ماژولار مبتنی بر اصول SOLID، طراحی شیشه‌ای (Glassmorphism) و پخش‌کننده صوتی واکنش‌گرا (Mobile-First).

---

## 🎧 مشخصات و ویژگی‌های کلیدی

### ۱. بخش استریم عمومی (`/music/{slug}`)
- **بدون نیاز به ثبت‌نام یا حساب کاربری:** مخاطبان مستقیماً و بدون مزاحمت از طریق پیوند اختصاصی وارد صفحه می‌شوند.
- **طراحی منطبق بر نمونه مرجع:**
  - کارت شناور شیشه‌ای (Glassmorphism) با انیمیشن‌های نرم روی گرادیانت ملایم بر اساس رنگ گرم برند (`#ffd7ab`)
  - **فریم پیشرفت مربعی با گوشه‌های خمیده (Squircle Progress Frame):** چرخش ساعت‌گرد و پیوسته نوار پیشرفت به صورت مربعی با گوشه‌های گرد دور کاور و لوگوی مرکزی
  - **لوگوی برند:** به جای کاور آلبوم، لوگوی ثابت و باکیفیت برند در کادر هم‌مرکز با گوشه‌های خمیده قرار دارد
  - **نشانگر زمان:** زمان سپری شده در کادر کپسولی زیر لوگو
  - **اطلاعات قطعه:** عنوان برجسته و نام هنرمند با آیکون‌های علاقه‌مندی (Heart) و اشتراک‌گذاری (Share)
  - **موج صوتی (WaveSurfer.js):** رسم امواج صوتی با قابلیت جست‌وجو (Scrubbing) و رنگ‌آمیزی بخش پخش‌شده با رنگ اصلی برند
  - **کنترل‌های پخش تک‌آهنگ اختصاصی:** ۱۰ ثانیه به عقب (`۱۰-`)، دکمه برجسته پخش/توقف با سایه درخشان، ۱۰ ثانیه به جلو (`۱۰+`)، تکرار خودکار قطعه (Repeat) و کلید قطع/وصل صدا (Mute)
  - **تمرکز انحصاری بر قطعه:** بدون لیست پخش دیگر آهنگ‌ها، با تمرکز ۱۰۰٪ روی قطعه فراخوانی‌شده
  - **فوتر شبکه‌های اجتماعی:** آیکون‌های تعاملی اینستاگرام، تلگرام، شماره تماس و وب‌سایت (کاملاً پویا از تنظیمات مدیر)
  - **ماژول اشتراک‌گذاری:** کپی پیوند، تلگرام، واتس‌اپ، توییتر/X و اینستاگرام

### ۲. استریم مستقیم از لینک و استریم امن با بازه بایت‌ها (HTTP 206 Range Streaming)
- امکان استریم مستقیم موزیک از لینک‌های اینترنتی با استخراج خودکار متادیتا (Auto-probe) و استریم از فایل‌های آپلود شده
- نشانی‌های لینک مبدا یا مخزن ابری هرگز برای کاربر فاش نمی‌شوند (Masked Origin URL).
- نقطه پایانی `/stream/{slug}` با پاسخ `206 Partial Content`، امکان بافر بهینه، پرش به هر نقطه از آهنگ (Seeking) و ادامه پخش را فراهم می‌کند.

### ۳. پنل مدیریت یکپارچه (`/admin`)
- **احراز هویت امن:** مبتنی بر JWT در کوکی‌های HttpOnly با قابلیت "مرا به خاطر بسپار".
- **تغییر رمز عبور مدیر:** امکان تغییر رمز عبور ورود به پنل با اعتبارسنجی امن هش bcrypt مستقیماً در صفحه تنظیمات.
- **ماژول بارگذاری و ثبت موزیک:**
  - ثبت مستقیم از طریق پیوند اینترنتی مستقیم با تشخیص خودکار مشخصات فایل
  - بارگذاری مستقیم فایل با کشیدن و رها کردن (Drag & Drop) فرمت‌های صوتی
  - درون‌ریزی از Google Drive با ذخیره دائمی
  - استخراج خودکار متادیتا و محاسبه مدت زمان و بیت‌ریت
  - تولید شناسه یکتای تصادفی NanoID (بدون شناسه‌های قابل حدس)
- **کتابخانه موزیک:** جدول کامل با نشان «استریم مستقیم»، جستجو، نمایش دفعات پخش، ویرایش عنوان/هنرمند/آلبوم، حذف دائم، و کپی پیوند استریم.
- **تنظیمات و امنیت:** تغییر لوگوی سراسری برند، تعیین رنگ اصلی و ثانویه با پالت رنگی تعاملی، ویرایش پیوندهای تماس و تغییر رمز عبور.

## 🏗 ساختار فنی پروژه (Tech Stack)

- **Frontend:** Next.js 14 (App Router), React, TypeScript, Tailwind CSS, WaveSurfer.js, Lucide Icons, Framer Motion
- **Backend:** NestJS 10, Prisma ORM, Storage Adapter (Cloudflare R2 S3-Compatible & Local), Audio Metadata Engine
- **Database:** PostgreSQL (سازگار با SQLite برای توسعه محلی)
- **Security:** Helmet, Throttler Rate Limiting, Cookie-Parser, Class-Validator, NanoID

## 🚀 راهنمای راه‌اندازی و اجرا

### اطلاعات ورود پیش‌فرض مدیر:
- **نشانی ورود:** `http://localhost:3000/login`
- **نام کاربری:** `admin`
- **رمز عبور:** `admin123`

### نمونه صفحه استریم:
- `http://localhost:3000/music/f8Ka2Lp`
- `http://localhost:3000/music/m9Xq3Nw`

### دستورات اجرای همزمان:
```bash
# نصب وابستگی‌ها
npm --prefix backend install
npm --prefix frontend install

# اجرای بک‌اند (پورت 4000)
npm run dev:backend

# اجرای فرانت‌اند (پورت 3000)
npm run dev:frontend
```

### پیکربندی Cloudflare R2 در `backend/.env`:
```env
STORAGE_DRIVER="r2"
R2_ACCOUNT_ID="your_account_id"
R2_ACCESS_KEY_ID="your_access_key"
R2_SECRET_ACCESS_KEY="your_secret_key"
R2_BUCKET_NAME="your_bucket_name"
```
*(در صورت خالی بودن این مقادیر، درایور خودکار روی `local` فعال است و در پوشه `uploads/` ذخیره می‌شود).*
